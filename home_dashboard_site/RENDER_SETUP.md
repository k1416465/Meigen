# Render 共有機能の設定

## Render側
1. Renderで既存のWeb Serviceを開き、同じリージョンにPostgreSQLデータベースを作成します。
2. Web Service の Environment に `DATABASE_URL` を追加し、データベースの **Internal Database URL** を設定します。
3. GitHubへこのZIPの内容を反映し、Renderで再デプロイします。
4. `/share` を開き「共有スペースを作成」を押します。表示されたQRコードを自分のスマホで読み取ります。

## 共有されるもの
- 設定ページで選択したクラス、路線、天気の地域、外観
- カレンダーで追加・編集・削除した個人予定（同じ共有スペースに参加した端末間）

## 注意
- QRコードと共有リンクは、パスワードの代わりになる秘密情報です。他人に送ったり、公開リポジトリやSNSへ載せたりしないでください。
- 共有スペースを作成したあと、リンクを知っている人は参加できる設計です。紛失・流出した場合は、共有スペースを作り直してください。
- `personal_events.json` の既存データは削除・移行せず、そのまま同梱しています。既存の共有予定はこれまで通り表示されます。
- DBを設定しない場合、元のCookie/localStorage方式で利用できます。共有機能は利用できません。
- この改修版は構文チェック済みですが、この実行環境にはFlask等の依存パッケージがないため、実際のWebリクエストを使った結合テストは未実施です。Renderへ反映する前にバックアップを取ってください。
