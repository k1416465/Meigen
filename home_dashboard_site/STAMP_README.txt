スタンプ機能の使い方

1. 画像ファイルを static/stamps/ フォルダに配置してください。
   対応形式: PNG / JPG / JPEG / GIF / WEBP / AVIF / BMP
2. /stamp を開くと、新しい画像が自動で一覧に登録されます。
3. 一覧ページの「スタンプ管理」から、タイトル・人物名・タグの編集、画像の削除、人物・タグの表示順設定ができます。
4. 管理画面は既存の録音管理ログインを共用します。app.py の RECORDING_ADMIN_PASSWORD に管理用パスワードを設定してください。
5. 画像を管理画面から削除すると static/stamps/ 内の実ファイルも削除されます。必要な画像は事前にバックアップしてください。

スタンプ情報は stamps.db に保存されます。既存の recordings.db / recordings データには変更を加えません。


番号について：スタンプ管理画面で各スタンプの番号（1以上）を設定できます。一覧のカードにも番号が表示され、「番号順（1〜）」で並び替えできます。既存データの初回更新時は、既存スタンプにID順で1から番号が設定されます。新しく追加した画像には最大番号の次の番号が自動設定されます。
